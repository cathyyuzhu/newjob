自动分析设置

需要设置 ANTHROPIC_API_KEY（Claude）或 DEEPSEEK_API_KEY（DeepSeek）环境变量，用哪个由 config.json 里的 llm_provider 字段决定（暂无界面开关，需直接编辑该文件）。点击职位的"AI 分析"会调用对应 API 计算匹配度并写入追踪表，匹配度 ≥70% 时还会生成定制简历 + cover letter（会产生 API 调用费用）。

Easy Apply 自动回答设置

LinkedIn Easy Apply 半自动投递遇到筛选问题时，会用这里配置的答案自动填写并点"下一步"；遇到下面没覆盖到的问题会停在那一步，等你手动填。不会自动点击最终的"提交申请"，这一步永远需要你自己确认。

自动化会用"问题关键词"去匹配 Easy Apply 表单里问题的文字，包含这个关键词就填对应答案；没匹配上任何一行才会停下来
