# 阶段 0 素材包（3 篇内容 + 问卷 + 私信话术）

> 配套 [spec/monetization-plan.md](../spec/monetization-plan.md) 的阶段 0。目标只有一个：**7 天内 ≥30 份问卷 且 ≥5 人选"会买"**（或 ≥2 人预约 ¥399 服务）。达不到就停，回去投简历。
>
> 总投入控制在 3–5 小时。**这不是产品发布，是一次需求验证**——所以不要为了发帖去改代码、做落地页、设计 logo。

---

## 第 0 步（20 分钟）：把数字换成今天的真实值

下面三篇草稿里所有 `【】` 都是占位符，用的是 2026-08-18 那份快照的旧数字。**发之前必须换成今天的真实值**——数字是这几篇内容唯一的说服力来源，用错了整篇就废了。

在项目目录跑（只读，不改任何东西）：

```bash
sqlite3 -header -column jobs.db "
-- ① 库里的总体分布
SELECT status, COUNT(*) AS 条数 FROM jobs GROUP BY status;
SELECT application_status, COUNT(*) AS 条数 FROM jobs GROUP BY application_status;

-- ② 选题二的核心数字：高分职位的真实转化率
SELECT
  SUM(CASE WHEN overall_match >= 0.7 THEN 1 ELSE 0 END) AS 高分总数,
  SUM(CASE WHEN overall_match >= 0.7 AND status = 'dismissed' THEN 1 ELSE 0 END) AS 高分却被我忽略,
  SUM(CASE WHEN overall_match >= 0.7 AND application_status <> 'not_applied' THEN 1 ELSE 0 END) AS 高分且真投了
FROM jobs;

-- ③ 最有冲击力的一句：被忽略的最高分 vs 实际投出去的分数
SELECT company, title, ROUND(overall_match,3) AS 分数 FROM jobs
  WHERE status='dismissed' AND overall_match IS NOT NULL ORDER BY overall_match DESC LIMIT 3;
SELECT company, title, ROUND(overall_match,3) AS 分数 FROM jobs
  WHERE application_status <> 'not_applied' ORDER BY overall_match DESC LIMIT 5;

-- ④ 选题一的降噪战果
SELECT SUM(found) AS 抓到, SUM(added) AS 入库, SUM(skipped_duplicate) AS 去重挡掉,
       SUM(skipped_irrelevant) AS 粗筛挡掉 FROM collect_runs;

-- ⑤ 选题三：忽略原因的分布
SELECT tags, COUNT(*) AS 次数 FROM job_dismiss_reasons GROUP BY tags ORDER BY 次数 DESC;

-- ⑥ 成本（可以在帖子里佐证 BYOK 到底要花多少钱）
SELECT provider, COUNT(*) AS 调用次数, ROUND(SUM(cost_usd),2) AS 总花费美元 FROM llm_calls
  WHERE ok=1 GROUP BY provider;
"
```

**发之前的自查**：公司名和职位名要不要打码？③ 那两条查询会带出真实公司名。建议**保留"我投了哪些"的公司名（增加可信度），打码"我忽略了哪些"的公司名**——被点名"高分却被嫌弃"对那家公司不公平，也可能影响你以后投它。

## 第 1 步（30 分钟）：建问卷

用腾讯问卷 / 金数据 / Google Form 都行，**5 题以内，2 分钟填完**。题目照抄：

1. **你现在在找什么方向的工作？**（单选）
   - 产品 / 运营
   - 研发 / 算法
   - 数据 / 分析
   - 设计
   - 其他（填空）

2. **你主要投什么类型的公司？**（单选）
   - 外企 / 港美股上市
   - 英文远程岗（海外雇主）
   - 国内大厂
   - 国内中小厂 / 创业公司

3. **求职过程中最耗你时间的是哪一步？**（多选，最多 2 项）
   - 每天翻各个平台找新岗位
   - 判断这个岗到底值不值得投
   - 每投一个就要改一版简历
   - 写 cover letter
   - 面试准备
   - 记录投了哪些、进展到哪一步

4. **如果有这样一个工具**：跑在你自己电脑上（简历和数据不上传任何服务器）、自动每天搜岗位并用 AI 算匹配度、能生成定制简历和面试准备，但需要你自己去申请一个 AI 的 API Key（大概 5 分钟，每月自付几块到几十块）——**一次性 ¥129 买断，你会买吗？**（单选，**这是整份问卷唯一真正重要的一题**）
   - 会买
   - 看情况 / 想再了解一下
   - 不会买
   - 不会买，因为要自己配 API Key 太麻烦

5. **（选填）想第一批试用吗？**
   - 我在招 3–5 个内测用户，早鸟价 ¥69，装不上或不好用无条件退款。愿意的话留个微信/邮箱：____
   - 或者：想让我用这套工具帮你亲自跑一次完整的岗位分析 + 简历定制 + 面试准备（¥399），也留个联系方式：____

> 第 4 题一定要把"要自己配 API Key"和"数据不上传"**都写进去**。藏着门槛换来的"会买"是假数据，到了收钱那一步会全部流失。

## 第 2 步（2–3 小时）：三篇内容

三个选题递进：**① 有用 → ② 可信 → ③ 独特**。建议隔天发一篇，别一天全发完。

---

### 选题一《我用 AI 筛了 【281】 个职位，最后只投了 【5】 个》

**主发**：小红书 · **改写后转**：即刻

小红书版（口语、短句、有钩子，配 2–3 张截图：职位列表页、匹配度分析结果、每日待办清单）：

> 离职找工作第 N 天，我实在受不了每天刷 5 个招聘 App，就自己写了个程序。
>
> 它每天早上 8 点自动去 Indeed 搜我设的关键词，把新岗位抓回来，去重，然后拿我的简历跟每个 JD 做一次匹配度分析。
>
> 跑到今天的真实数据：
> 📥 抓回来 【281】 个岗位
> 🚮 【63%】 直接被规则挡掉（标题跟我搜的完全不沾边、地点对不上）——这部分连 AI 都不调用，省钱
> 🔁 去重又挡掉一批
> ✅ 最后真正需要我看的：【5】 个
>
> 从"每天刷两小时"变成"每天看 5 条"。
>
> 最爽的不是自动化，是**心理负担没了**。以前每天刷完还是焦虑"是不是漏了什么好岗"，现在知道漏不掉。
>
> 完全跑在自己电脑上，简历不上传任何服务器（找工作的人应该都懂这个顾虑）。
>
> 有人想要的话我整理一下，评论区说一声👇

即刻版：同样内容，但**把三个数字提到第一句**，删掉 emoji 列表，加一句技术细节（"两层零成本粗筛挡掉 63%，这部分完全不调 LLM"）——即刻的人吃这套。

### 选题二《AI 给我打 83 分的岗位，我一个都没投》★ 传播力最强

**主发**：即刻 / V2EX · **改写后转**：小红书

这篇是三篇里最该认真写的。**它反的是所有同类产品的宣传口径**，而你有数据。

> 我给自己写了个 AI 求职工具，跑了三周之后，我发现它的核心功能是坏的。
>
> 它会给每个岗位算一个"匹配度"。越过 70% 就标绿，意思是"这个你该投"。
>
> 现在库里越过 70% 的有 【37】 个。
> 我实际投了几个？【5】 个。
> 我亲手按"忽略"的有几个？【11】 个。
>
> 最扎心的是：**被我忽略的那些里面，分数最高的一个是 【0.835】——比我真正投出去的每一个都高。**
>
> 也就是说，那个最大最醒目的绿色数字，跟我真实的决策几乎无关。
>
> 我一开始以为是 prompt 没调好。后来想明白了：**匹配度算的是"你能不能干这个岗"，而我决定投不投，看的是"我想不想干这个岗"。** 这是两件完全不同的事，而市面上所有工具都在算前者。
>
> 更要命的是这个方向结构上就走不通：平台方拿不到你个人的足量信号——一个人一辈子也就投几百次，还分散在各个平台。所有的反馈学习都发生在招聘方那一侧（HR 点了 accept/reject，平台学 HR 的偏好），求职者这一侧几乎没人做。
>
> 但如果工具跑在你自己电脑上，情况就反过来了：你每一次"忽略"、每一次"收藏"、每一次真的投了，信号全在你自己的库里。
>
> 所以我现在在做的是：**让它从我按下的每一个"忽略"里，学我到底讨厌什么样的工作。**
>
> （下一篇写这个）

V2EX 版：同样骨架，但**加技术细节**——双因子模型怎么算的、两层粗筛怎么省钱、为什么不训练模型而是总结成一段自然语言注入 prompt。V2EX 讨厌营销腔，喜欢"我踩了坑，数据在这"。

### 选题三《我让求职工具记住了我讨厌什么样的工作》

**主发**：即刻 / 小红书 · 这篇末尾**放内测招募**

> 接上一篇：AI 算出来的匹配度，跟我真实想投的岗几乎无关。
>
> 我的解法很土：每次我按"忽略"，它多问一句"为什么"——薪资不符 / 职能不对 / 公司不感兴趣 / 地点 / 行业 / 层级不匹配，外加一行想说啥说啥。
>
> 攒够一批之后，一次 AI 调用把它们总结成一段话，我管它叫"偏好档案"。这段话会被塞进以后每一次匹配分析的 prompt 里。
>
> 我目前攒了 【52】 条忽略记录，总结出来的东西比我自己讲得还准，大意是：【这里贴一两句你真实的偏好档案内容，删掉敏感信息】
>
> 这个东西大厂做不了。不是技术难，是结构问题——**平台方拿不到你个人的足量信号**。而一个跑在你自己电脑上的工具，天然就有全部信号。
>
> ——
>
> 现在这个工具我自己每天在用。想找 **3–5 个人**一起用两周，把安装流程和别人简历上的坑趟出来。
>
> · 早鸟 ¥69（之后卖 ¥129），**装不上、跑不通、不想要了，无条件退**
> · 跑在你自己电脑上，简历和数据不经过我的服务器（我也看不到）
> · 需要你自己申请一个 AI 的 API Key，大概 5 分钟，每月自付几块到几十块
> · 我会跟你一起装（大概 30 分钟），因为我需要在旁边看你卡在哪
> · 内测期只开 Indeed，不碰 LinkedIn 账号
> · 我不承诺你能拿到 offer，只承诺帮你少看无关岗位、少投不想去的岗
>
> 想试的话填这个（2 分钟）：【问卷链接】

## 第 3 步：私信话术（招募内测）

对问卷里选了"会买"或留了联系方式的人，逐个私信。**不要群发**。

> 嗨，看到你填了问卷说在找【他填的方向】的岗，正好我在招 3–5 个内测。
>
> 简单说：一个跑在你自己电脑上的求职工具，每天自动搜岗、用 AI 拿你的简历算匹配度、能生成定制简历和面试准备。数据不经过我这边。
>
> 早鸟 ¥69，装不上或者用两天觉得没用，直接退，不用理由。
>
> 有个前提要先说清楚：现在还没做安装包，得我陪你装一次，大概 30 分钟（我需要在旁边看你卡在哪，这正是内测的目的）。另外需要你自己去申请一个 API Key，5 分钟的事，每月自付几块到几十块。
>
> 方便的话这周找个时间？

**开口原则**：不要说"能不能帮我测一下"——那是求人情，换回来的是假反馈和"挺好用的"。要给判断题，不要给人情题。

## 第 4 步：7 天节奏

| 天 | 做什么 | 时间 |
|---|---|---|
| D1 | 跑 SQL 换数字、建问卷 | 50 分钟 |
| D2 | 发选题一（小红书 + 即刻） | 40 分钟 |
| D4 | 发选题二（即刻 + V2EX） | 60 分钟 |
| D6 | 发选题三（带内测招募） | 40 分钟 |
| D2–D7 | 每天花 15 分钟回评论/私信 | 每天 15 分钟 |
| D7 | 数问卷，对门槛 | 15 分钟 |

**D7 结算**：≥30 份 且 ≥5 人选"会买"（或 ≥2 人预约 ¥399）→ 进阶段 0.5。达不到 → 停，回去投简历，别改门槛。

**期间不要做的事**：改代码、做落地页、设计 logo、注册域名、拍视频。任何一件都会把 5 小时变成 5 天。

---

## 两个要提前想清楚的

1. **实名发帖的取舍**：这几篇会公开你正在找工作。在小红书/即刻/V2EX 基本只有好处（HR 反而觉得你有主动性，也是面试时"你最近在做什么"的一个好答案）。但**脉脉不一样**——你的前同事和目标公司 HR 都在那儿，发之前想清楚要不要实名。
2. **口径守住**：不承诺求职结果、不承诺"提高通过率 X%"、不说"包 offer"。既无法证实，也踩国内求职服务类广告的合规线。统一说成"帮你少看无关岗位、少投不想去的岗"。
